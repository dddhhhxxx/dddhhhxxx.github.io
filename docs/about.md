# 关于

嵌入式底层软件工程师，在杭州做系统交付，从 MCU 裸机、RTOS 一路到 Linux 内核驱动和 Android BSP，主要平台是瑞芯微（Rockchip）和全志（Allwinner）的 SoC。

这个博客用来记录两件事：

1. **现场排查过的问题** —— 内核 panic、设备树配错、外设不通、启动卡死，把现象、定位过程和结论写下来，避免同一个坑踩第二次。
2. **底层机制的梳理** —— 数据通路、驱动框架、硬件模块之间的关系，写成能回头查的笔记。

内容按四个方向组织：**软件系统交付**（MCU / RTOS / Linux / Android）、**硬件平台与外设**（SoC / MCU）、**复杂模块**（摄像头 / 显示）、**性能与功耗**。

## 写作原则

- 结论前置，能跑的命令直接贴出来，不讲空话
- 涉及寄存器、设备树、日志的，写具体路径和数值
- 不确定的地方明确标注，不把"可能"写成"肯定"
